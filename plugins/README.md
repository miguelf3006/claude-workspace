# Plugins

Plugin/skill-bundle folders backed up here so they're available across devices.

- **ai-job-search** — job search automation toolkit
- **book-to-skill** — converts books into Claude skills
- **grill-me** — devil's advocate critique skill
- **hallmark** — hallmark app/tool source
- **hormozi**, **hormozi-offers**, **hormozi-leads**, **hormozi-money-models**,
  **hormozi-acquisition-system** — Alex Hormozi-based skill bundles
- **marketing-skills** — Corey Haines' marketing skills plugin
  (https://github.com/coreyhaines31/marketingskills, MIT licensed)
- **ponytail** — plugin bundle
- **skill-seekers** — skill-seekers toolkit
- **superpowers** — Superpowers skill/plugin framework

As you install more plugins, drop their folders here to keep them backed up
and synced across devices.
